# FIFA 21–23 Player Performance Analysis

## Project Overview
Analyzed 60,000+ FIFA player records from 2021–2023 using RStudio to explore relationships between player characteristics and performance ratings.

## Tools and Methods
- R / RStudio
- Data cleaning and exploratory data analysis
- Data visualization
- Bootstrapping and hypothesis testing

## Project Highlights
- Prepared 60,000+ player records across three datasets.
- Investigated age, height, nationality, and overall performance ratings.
- Applied statistical techniques to examine player performance trends.
- Presented findings through a research poster with R-generated visualizations.
